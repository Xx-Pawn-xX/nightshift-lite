
# NIGHTSHIFT//Lite

A futuristic 3D racing game built with Three.js.

## Technology
- Three.js
- JavaScript ES Modules
- WebGL
- HTML5
- CSS3

## Controls

| Key | Action |
|---|---|
| W / Arrow Up | Accelerate |
| S / Arrow Down | Brake / Reverse |
| A / Arrow Left | Steer Left |
| D / Arrow Right | Steer Right |
| Space | Drift |

Touch controls are included for mobile devices.

## Deployment

1. Upload all project files to the repository root.
2. Open repository Settings.
3. Navigate to Pages.
4. Select Deploy from a branch.
5. Select main.
6. Select / (root).
7. Save.

Open the published GitHub Pages URL.

## Requirements
- Modern browser
- WebGL support
- Internet connection for Three.js CDN
